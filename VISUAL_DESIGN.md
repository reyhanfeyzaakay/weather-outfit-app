# VISUAL DESIGN SYSTEM

## 1. Mobile App Layers
- **Layers Overview:**  
  - **Background Layer:** Base layer containing background images or colors.
  - **Content Layer:** Displays all main app content, including text, images, and icons.
  - **Overlay Layer:** Contains modals, tooltips, and other interactive elements.

## 3. Color Palette
| Color Name | Hex Code | Usage  |
|------------|----------|--------|
| Primary    | #4A90E2 | Main buttons, highlights |
| Secondary  | #50E3C2 | Accents, secondary elements |
| Background  | #FFFFFF | App background |
| Text Color | #4A4A4A | Main text color |
| Error      | #D0021B | Error messages |

## 4. Typography System
- **Fonts:**
  - **Heading Font:** Roboto Bold, 24px, #4A4A4A
  - **Body Font:** Roboto Regular, 16px, #4A4A4A
  - **Caption Font:** Roboto Light, 12px, #B0B0B0

## 5. Component Specifications
### 5.1 Buttons
- **Primary Button:**  
  - Background: #4A90E2  
  - Font: Roboto Bold  
  - Height: 48px  
  - Width: 100% (responsive)  

### 5.2 Input Fields
- **Text Input:**  
  - Border: 1px solid #D0D0D0  
  - Height: 44px  
  - Padding: 10px

## 6. Animation Guidelines
- **Button Hover Animation**:  
  - Scales to 1.05 on hover.  
  - Duration: 300ms.  
- **Loaders:**  
  - Spinning loader for loading states.

## 7. Responsive Design Breakpoints
| Device Type       | Width    |
|-------------------|----------|
| Mobile            | ≤ 768px  |
| Tablet            | 769px - 1024px  |
| Desktop           | ≥ 1025px  |

This design system aims to create consistency throughout the WeatherFit application, providing a clear guide for developers and designers.
