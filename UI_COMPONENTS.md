# UI Components Showcase

## Buttons
### Example:
```html
<button class="btn-primary">Primary Button</button>
```
### CSS Classes:
- `btn-primary`: Styles for primary buttons.
- `btn-secondary`: Styles for secondary buttons.

---

## Cards
### Example:
```html
<div class="card">
  <h3>Card Title</h3>
  <p>This is an example card description.</p>
</div>
```
### CSS Classes:
- `card`: Basic card styles.
- `card-header`: Header styles for cards.

---

## Lists
### Example:
```html
<ul class="list-items">
  <li>List Item 1</li>
  <li>List Item 2</li>
</ul>
```
### CSS Classes:
- `list-items`: Styles for lists.
- `list-item`: Styles for individual list items.

---

## Inputs
### Example:
```html
<input type="text" class="input-text" placeholder="Enter text here" />
```
### CSS Classes:
- `input-text`: Styles for text inputs.
- `input-error`: Styles for input errors.
