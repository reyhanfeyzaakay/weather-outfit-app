# # Outfit Pack

Outfit Pack is an intelligent mobile application designed to simplify daily outfit decisions by combining real-time weather data with user preferences.

By entering your location and checking current weather conditions, the app generates personalized outfit suggestions tailored to your environment. In addition, Outfit Pack creates a smart packing list to ensure you are always prepared for your day.

## ✨ Features

### 🌍 Location & Weather-Based Suggestions
- Uses real-time location and weather data
- Recommends outfits suitable for temperature, rain, wind, and overall conditions

### 🎯 Style Filtering System
- Users can customize their outfit preferences
- Select from different styles:
  - Formal
  - Informal (Casual)
  - Sporty
- The system adapts suggestions based on selected style

### 🎒 Smart Packing List
- Generates a personalized list of items to carry
- Examples:
  - Umbrella (rainy weather)
  - Sunglasses (sunny conditions)
  - Jacket (cold weather)

### ⚡ User-Centered Experience
- Fast and simple interface
- Minimal input, maximum efficiency
- Designed for everyday use

## 🎯 Purpose

Outfit Pack aims to eliminate the daily stress of choosing what to wear by providing smart, data-driven recommendations. It also helps users stay organized and prepared through intelligent packing suggestions.
